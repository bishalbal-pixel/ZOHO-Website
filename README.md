# ZOHO-Website

A responsive landing-page recreation that follows the layout and section structure of the [Zoho homepage](https://www.zoho.com/). It uses an original, fictional brand called **"Orbia"**, so it doesn't copy Zoho's logo, trademarks or customer content.

## Sections
Header · Hero with featured apps · Full-stack cloud & agent builder cards · All-in-one suite · Brands · Story cards · Enterprise · Values · Stats (animated counters) · Newsroom · Sign-up CTA · Footer

## Tech
Plain HTML, CSS and vanilla JavaScript. There are no build steps.

## Run locally
Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy
Turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).
